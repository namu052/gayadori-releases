가야돌이 친구 초대

친구가 가야돌이 친구 초대 링크를 보냈어요.

가야돌이 앱에서 열기

앱이 열리면 초대한 친구의 펫 이름이 보이고, 「친구 신청」을 누르면 신청이 가요. 친구가 받아 주면 친구가 돼요.

앱이 열리지 않나요?

가야돌이 앱(PC는 메신저, 휴대폰은 「친구」 탭) → 「친구 추가」 → 「코드·링크로 찾기」에 아래 링크를 붙여 넣으세요.

링크가 잘못됐어요. 초대한 친구에게 다시 보내 달라고 해 주세요.

이 페이지는 아무것도 저장하거나 보내지 않아요. 링크 속 초대 표시는 주소의 # 뒤에 있어서 이 페이지를 연 서버에도 가지 않아요.
