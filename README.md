# 가야돌이 데스크톱 펫 — 설치 파일

바탕화면에서 함께 지내는 가야돌이 펫의 설치 파일과 자동 업데이트 정보를 배포하는 저장소입니다. (소스 코드는 비공개)

## 내려받기
[최신 릴리스](https://github.com/namu052/gayadori-releases/releases/latest)에서 운영체제에 맞는 파일을 받으세요.

| 운영체제 | 파일 |
|---|---|
| Windows 10/11 (64비트) | `gayadori_<버전>_x64-setup.exe` |
| macOS (Apple Silicon·Intel) | `gayadori_<버전>_universal.dmg` |
| Linux | `.AppImage` 또는 `.deb` |

- 설치하면 로그인할 때 자동으로 켜지고, 새 버전이 나오면 스스로 업데이트합니다(6시간마다 확인).
- 아직 코드 서명 인증서가 없어 처음 실행할 때 경고가 뜰 수 있습니다.
  - Windows: "Windows의 PC 보호" 창에서 **추가 정보 → 실행**
  - macOS: 앱을 오른쪽 클릭 → **열기**

## 이용 안내
가야돌이 캐릭터와 그림은 저작권자의 것이며 개인적인 사용으로만 제공됩니다. 재배포·상업적 이용은 허용되지 않습니다.
